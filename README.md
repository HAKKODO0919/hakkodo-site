# 商品ページサイト(土台)

商品A・商品B・商品Cの商品説明ページです。QRコードで固定URLに誘導し、
内容(説明文・写真・原材料など)はあとから自由に更新できる構成になっています。
日本語・Català(カタルーニャ語)・Español(スペイン語)・English(英語)の
4言語をページ右上の切り替えメニューで切り替えられます。

【追記】現在、実際に販売している商品は「熟成味噌(赤味噌)」の1商品です。
`products/miso/` が現在使用中の商品ページで、固定URLは
`/products/miso` です。商品A・B・Cのファイルはサンプルとして
そのまま残していますが、今のトップページからはリンクされていません。
将来、新しい商品を追加するときの参考にしてください。

また、商品ページとは別に「レシピ」の仕組みも用意しました
(`recipes/` フォルダ)。レシピを追加・編集しても、商品ページの
URLやQRコードには一切影響しません。詳しくは下記の
「レシピ機能について」をご覧ください。

## 【追記】サイト全体の構成(2026年9月〜)

サイトを「個別ページの寄せ集め」ではなく、以下のナビゲーション構造を
持つ1つのサイトとして整理しました。

```
TOP (index.html)
├─ 商品 (products/)
│   └─ 赤味噌 (products/miso/) … 今後、商品が増えたら products/商品名/ を追加
├─ レシピ (recipes/)
│   └─ 各レシピ (recipes/レシピ名/) … 今後もどんどん追加できます
├─ ワークショップ (workshops/)
│   ├─ ワークショップ紹介 (workshops/index.html)
│   └─ 開催スケジュール (workshops/schedule/)
├─ 新着情報 (news/)
└─ お問い合わせ (contact/)
```

`index.html`(トップページ)は、以前は商品一覧を兼ねていましたが、
現在はサイト全体の入口(ブランド紹介+各セクションへの導線)専用の
ページになりました。商品一覧は `products/index.html` に移動しています
(内容・デザインは以前のトップページのままです)。

【追記】現在は商品が「熟成味噌(赤味噌)」の1点だけのため、ヘッダーの
「商品」リンクは `products/index.html`(一覧)を経由せず、
`products/miso/index.html`(商品詳細)に直接つなげています
(`assets/nav.js` の `NAV_ITEMS`)。`products/index.html` 自体や
`initProductList` の仕組みはそのまま残してあるので、商品が2点以上に
増えたら、`NAV_ITEMS` のhrefを `products/index.html` に戻すだけで
一覧ページが復活します。

**全ページ共通のナビゲーションについて**

すべてのページの上部に、`assets/nav.js` が描画する共通ナビゲーションが
表示されます。新しいページ(セクション)を追加したいときは、
`assets/nav.js` の `NAV_ITEMS` に1行追加するだけで、全ページの
ナビゲーションとトップページの導線ボタンの両方に自動的に反映されます。
表示文字は `assets/i18n.js` の `navXxx` キーで管理しています。

**ワークショップ・新着情報について**

どちらもまだ内容が決まっていないため、`workshops/schedule/index.html`
`news/index.html` は「現在は空欄(準備中の表示)」の状態です。
レシピと同じように、データファイルを1件追加するだけで表示されるように
なっています。詳しくは下記の各セクションをご覧ください。

**作り手について / お問い合わせについて**

独立した「作り手について」ページは廃止し、ナビゲーションからも
削除しました。商品ページ(`products/miso/`)内にもともとある
「作り手について」のセクションは、内容を変更せずそのまま残しています。

`contact/index.html` は、商品ページの「作り手について」で既に
公開されているメールアドレスを使ったシンプルな連絡先ページです。

## 商品ページの固定URL

サイトを公開したときのアドレスを `https://example.com` とすると、

- 商品A: `https://example.com/products/a/`
- 商品B: `https://example.com/products/b/`
- 商品C: `https://example.com/products/c/`

このURLは今後変更しません。QRコードはこのURLから作成してください
(QRコード自体はまだ作っていません)。

【追記】現在実際に使用している商品ページの固定URLは次のとおりです。

- 商品名「HAKKODO MISO｜熟成赤味噌」(言語ごとに種類の表記が異なる): `/products/miso/`
  (旧URL `/products/aka-miso/` は、リポジトリ直下の `_redirects` で新URLへ301転送しています。
  印刷済みQRコードなどで旧URLが使われている可能性があるため、`_redirects` は削除しないでください)

商品ページの文章・写真・原材料・保存方法・賞味期限などをあとから
編集しても、このURL(`/products/miso/`)は変わりません。そのため、
QRコードを一度印刷すれば、内容を更新するたびに作り直す必要はありません。

将来、商品が増えた場合も `products/商品名/` のようにフォルダを
1つ追加すれば、その商品専用の固定URLを増やせます(既存の商品の
URLには影響しません)。

## 内容(説明文・写真・原材料)を更新する方法

`data/a.js` のようなファイルを編集するだけで、ページの内容が変わります。
HTMLやCSS、URLには一切触れる必要がありません。

写真のパス(`images`)は4言語で共通の1セットです。文章にあたる部分は
`translations` の中に `ja` / `ca` / `es` / `en` の4つ分を用意します。

```js
window.PRODUCT_DATA = {
  images: {
    hero: "images/a/main.jpg",
    gallery: ["images/a/photo1.jpg", "images/a/photo2.jpg", "images/a/photo3.jpg"]
  },
  updatedAt: "2026-09-01",
  translations: {
    ja: {
      name: "商品A",
      tagline: "一言キャッチコピー",
      price: "¥500(税込)",
      heroAlt: "商品Aのメイン写真",
      galleryAlt: ["商品Aの写真1", "商品Aの写真2", "商品Aの写真3"],
      description: "説明文。\n\n空行で段落が分かれます。",
      ingredients: ["原材料1", "原材料2"],
      allergens: ["小麦", "卵"],
      notes: "その他の注意事項"
    },
    ca: { /* Català版。ja と同じキーを用意します */ },
    es: { /* Español版。ja と同じキーを用意します */ },
    en: { /* English版。ja と同じキーを用意します */ }
  }
};
```

- 1行目の `window.PRODUCT_DATA = {` と最後の `};` はそのまま残し、
  中の値だけを書き換えてください。
- `translations` の `ja` `ca` `es` `en` は4つとも用意してください。
  一部の言語だけ翻訳が間に合っていない場合は、とりあえず日本語と同じ
  文章を仮で入れておけば表示は崩れません(あとで差し替えられます)。
- `price` `allergens` `notes` は不要なら削除、または空(`""` や `[]`)でも動きます。
- 写真は `images/` フォルダに置いて、`images.hero` / `images.gallery` に
  そのパスを書きます(先頭に `/` は付けません)。写真がまだ無い場合は
  自動で「写真準備中」(各言語表記)と表示されます。
- `heroAlt` / `galleryAlt` は目の不自由な方向けの読み上げ用テキストです。
  各言語で写真の内容を短く説明してください。

## 【追記】熟成味噌(赤味噌)で追加した項目について

`data/aka-miso.js` では、上記の項目に加えて、食品の商品ページに
必要な項目を追加しています。

- `netWeight` … 内容量(例: `"300g"`)
- `ingredientsNote` … 原材料についての補足(例: 有機認証原料であることなど)。
  「原材料」の一覧のすぐ下に表示されます。
- `storageMethod` … 保存方法
- `bestBefore` … 賞味期限について

これらもすべて任意項目です。空にすれば、そのセクションは表示されません。

## 【追記】レシピ機能について

商品ページとは別に、HAKKODOの味噌を日々の食卓で楽しむための
「小さなレシピ集」を掲載する仕組みを用意しました。
`recipes/` フォルダが商品ページ(`products/`)とは完全に独立しているため、
**レシピをいくつ追加・編集しても、商品ページのURLやQRコードには
一切影響しません。**

大量のレシピを掲載するレシピサイトを目指すものではないため、
デザインは商品ページと同じ雰囲気(フォント・色・余白・角丸)を
そのまま使い、レシピだけ別サイトのように見えないようにしています。

- `/recipes/` … レシピ一覧ページ。冒頭の説明文の下に、
  **実際にレシピが存在するカテゴリーだけ**が目次(ピル状のボタン)
  として並びます。目次をタップすると、そのカテゴリーのレシピ一覧まで
  ページ内でジャンプします。レシピが0件のときは「準備中」の
  表示になります
- `recipes/レシピ名/` … 個別レシピページ。商品ページと同じく、
  一度作った固定URLは編集しても変わりません。以下の共通フォーマットで
  表示されます。
  1. 料理写真(商品ページのメイン写真より控えめな高さで表示されます)
  2. 料理名
  3. 短い紹介文
  4. 材料
  5. 作り方
  6. アレンジ
  7. HAKKODOの味噌を使うポイント
- `data/recipes/_template.js` … 新しいレシピを追加するときにコピーして
  使う内容のひな形ファイル(このファイル自体は公開されません)
- `recipes/_template/` … 新しいレシピページを追加するときにコピーして
  使うページのひな形フォルダ(このページ自体は公開されません)

**レシピを1件追加する手順**

1. `data/recipes/_template.js` をコピーして
   `data/recipes/レシピ名.js` として保存し、内容を書き換える。
   `category` にはそのレシピのジャンル(例: `{ slug: "dressing", label: "ドレッシング" }`)を指定します。
   既存のレシピと同じジャンルなら同じ `slug`/`label` を、
   新しいジャンルなら新しい `slug`/`label` を指定するだけで、
   レシピ一覧の目次にカテゴリーが自動的に増えます
2. `recipes/_template/` フォルダをコピーして `recipes/レシピ名/` を作り、
   読み込むファイルを `data/recipes/レシピ名.js` に変更する
3. `recipes/index.html` の `initRecipeList([...])` の配列に
   `{ href: "レシピ名/index.html", data: window.RECIPE_DATA相当 }`
   を1行追加する

レシピの「作り方」の各手順は、今は文章だけのシンプルな箇条書きとして
表示されます。手順に `image` (写真のパス)を追加すると、その手順だけ
自動的に写真つきの見やすいレイアウトに切り替わります。写真は
いつでも後から追加・差し替えできます。

## 【追記】ワークショップ機能について

「開催日ごとに情報を追加・更新できる」構造として、レシピと同じ
パターンで作っています。1件のワークショップにつき、以下の項目を
掲載できます。

- 開催日 / 時間 / ワークショップ名 / 内容 / 場所 / 参加費 / 定員 / 予約方法

**ワークショップを1件追加する手順**

1. `data/workshops/_template.js` をコピーして
   `data/workshops/開催日など分かる名前.js` として保存し、内容を書き換える
2. `workshops/schedule/index.html` の `<script>` で、そのファイルを
   読み込む `<script src="...">` タグを追加する
3. 同じページの `initWorkshopSchedule([...])` の配列に
   `window.WORKSHOP_DATA` を1件追加する

開催予定が1件も無いときは「現在開催予定のワークショップはありません」
という表示になります。項目は空にすれば、その行だけ表示されません。

## 【追記】新着情報について

レシピ・ワークショップと同じパターンで、お知らせを追加できます。

**お知らせを1件追加する手順**

1. `data/news/_template.js` をコピーして
   `data/news/日付など分かる名前.js` として保存し、内容を書き換える
2. `news/index.html` の `<script>` で、そのファイルを読み込む
   `<script src="...">` タグを追加する
3. 同じページの `initNewsList([...])` の配列に
   `window.NEWS_DATA` を1件追加する

## 言語切り替えの仕組み

各ページ右上に言語選択メニューが表示され、選んだ言語は端末に記憶されます
(次に別の商品ページを開いたときも同じ言語で表示されます)。
「商品説明」「原材料」などの見出しや、戻るリンクといったサイト共通の文言は
`assets/i18n.js` の `UI_STRINGS` にまとまっています。将来さらに言語を
増やす場合は、`SUPPORTED_LANGS` と `UI_STRINGS` に言語を追加したうえで、
各商品の `data/*.js` の `translations` にも同じ言語コードを追加してください。

## パソコンで表示を確認する方法

`index.html` をダブルクリックしてブラウザで開くだけで確認できます。
サーバーの起動は不要です。

サーバー経由で確認したい場合は、このフォルダで以下を実行し、表示された
アドレス(例: http://localhost:8000)をブラウザで開くこともできます。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/serve.ps1 -Port 8000
```

## 公開(ホスティング)について

実際にQRコードから読めるようにするには、このフォルダをWebサーバー
(レンタルサーバー、Netlify、GitHub Pages など)にアップロードします。
すべてのリンクがフォルダ内の相対的な位置関係で書かれているため、
ドメインの「ルート」に置いても、サブフォルダに置いても、そのまま表示できます。
