ここに商品写真を置きます。

images/a/main.jpg     … 商品Aのメイン写真
images/a/photo1.jpg   … 商品Aのギャラリー写真1
images/a/photo2.jpg   … 商品Aのギャラリー写真2
images/a/photo3.jpg   … 商品Aのギャラリー写真3

images/b/... 、 images/c/... も同じ形式です。

ファイル名を変える場合は、data/a.js (b.js, c.js) の
src の値も同じファイル名に合わせて書き換えてください。

写真がまだない項目は、ページ上に「写真準備中」と表示されます。
